# tahayunusdemir.com

Personal portfolio + blog of Taha Yunus Demir (full-stack & Android developer). Bilingual EN (`/`) / TR (`/tr/`).

**Always load the project skill first:** `.claude/skills/tahayunusdemir-site/SKILL.md`. It holds the fixed stack, design rules, quality gates and the phase plan (`references/phases.md`).

## Layout
- `docs/` — content brief (facts), assets inventory, design brief, phase notes. Facts on the site must come from here.
- `research/` — framework/UI research, cloned example repos, saved pages, upstream skills. **Gitignored, read-only reference.**
- Site code (Astro) lives at the repo root from Phase 1 on.

## Commands (from Phase 1)
- `pnpm dev` · `pnpm astro check` · `pnpm build` · `pnpm preview`
- Deploy: `pnpm wrangler deploy` — only with Taha's explicit OK.

## Hard rules
- No invented facts; no phone number; no links to private repos.
- Ask before deploys, DNS changes, creating/pushing GitHub repos.
- Communicate with Taha in Turkish.
